# iyunga-sec.github.io
* File Architecture: Consists of 7 core HTML page files resting in the root folder, styling layouts managed through css/style.css, interactive operations via js/main.js, and visual branding assets stored inside the images/ directory.
* Portal Homepage (index.html): Displays the campus overview notice, temporary academic summary data tables, a click-event reading tracker, and a comprehensive institutional contact section at the bottom.
* Academic Directories (subjects.html & staff.html): Features structured informational layouts mapping available technical courses alongside teacher contact files and assignment tracks.
* Public Notice Desks (announcements.html & events.html): Manages a public bulletin matrix for parent communications and the upcoming campus activities calendar.
* Campus & Enrollment Profiles (facilities.html & admission.html): Lists operational infrastructure assets like laboratory blocks alongside requirements tables for student enrollment.
* Visual & Crest Alignment (CSS Layout): Implements modern tables layout formatting while binding the Iyunga Technical Secondary School badge and the National Emblem side-by-side in the header.
* Mobile Response Control (JavaScript Navigation): Executes active DOM listening logic that instantly collapses the navigation layout into a standard responsive hamburger menu on compact screens.
* Static Server Environment: Operates without backend or database dependencies, allowing anyone to read institutional data lists smoothly without registering or logging in.
